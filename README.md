# Project Title

Movie recommendator

## Summary

A customizable movie recommendation tool that explains its suggestions based on user reviews and ratings.

## Background

I want better movie recommendations. Current streaming services use algorithms, which hide their decision logic and their use every day extra time trying to decide what to watch. This algoritm would help that me and others could watch more diverse and interesting movies.


## How is it used?

* User (me) rates movies (1 to 5 star). For each movie user can also write what he liked about movie and what not. The text might also be divided to certain areas (genre, actors, plot, production). 
* The algorith compares the reviews of user to reviews in the data and makes suggestions. 
* User trains the algorithm by rating the suggestions that algorithm provides.


## Data sources and AI methods
Data should be available via GroupLens web site, IMDb Movie Reviews Dataset or Rotten Tomatoes Movies. https://grouplens.org/datasets/movielens/. I would analyze the data using Logistics regression to choose would I like a movie. I will also need techniques for text analysis like Natural Language Processing or TF-IDF.

## Challenges

The algorithm cannot recommend anything if the data is lacking and it is not sure how well suited the data is or is it available for use from all the services.

## What next?

If the basic idea works it could be expanded by adding option like where can I find the movie or you could filter the suggestion by streaming service. Algorithm could be expanded also to service or website where multiple users could rate movies and get recommendations.
